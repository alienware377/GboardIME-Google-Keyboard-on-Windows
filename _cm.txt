Fix stale/leaked relay text, taskbar overlap; add screen-height control

Stale buffer leaking old text into a new field:
Clicking a different WINDOWS text box tells the Android side nothing, so Gboard
can keep a word composing indefinitely. The previous fix deferred the CLEAR/SYNC
reset until composing ended - which therefore never happened: the reposition was
dropped, the relay buffer kept the PREVIOUS field's text, and Gboard's leftover
words hijacked the next tap (typing "commands"/"app" out of nowhere).
Resetting blindly is equally wrong - it orphans the prefix already relayed and
duplicates it (the doubled-first-letter bug the deferral was added to fix).
Fix: apply the reset immediately and call InputMethodManager.restartInput(), so
the buffer updates AND Gboard discards its stale composing region.

Placeholder text treated as field content:
An EMPTY Electron/Chromium field reports its rendered PLACEHOLDER through the
GroupControl/TextPattern fallback ("Type / for commands"), which was synced in as
real text; Gboard then autocorrected the user's first input into its trailing
word. Those wrappers also report page-relative caret offsets, so their text is
now treated as unreadable and the invisible shadow padding is used instead.
Native fields keep exact sync, plus a Name/HelpText placeholder guard.

Docking covered the taskbar:
_position_emulator docked against the FULL screen with a hardcoded 50px gap, but
a scaled display reserves more (96px at 200%), so the window sat under the
taskbar. It now docks inside the work area (SPI_GETWORKAREA) and clamps the
window to it, which also keeps a tall AVD on-screen on smaller displays.

New: Android screen height (hw.lcd.height) in the tray, alongside Keyboard size.
Keyboard size rescales the window but the emulator aspect-locks, so the
keyboard-to-textbox ratio never changes; only hw.lcd.height changes that, and it
is read at cold boot only. The menu writes config.ini and cold-restarts the
emulator with the required flags (-writable-system, -gpu host), then restores the
reverse tunnel, relaunches the relay and re-docks. Heights are Android-side
pixels so they are DPI-independent; the window clamp keeps them screen-safe.

Also removes the temporary wire-command tracing and a vestigial field.
